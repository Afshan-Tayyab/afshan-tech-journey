# 👨‍💻 Afshan's Tech Journey

A simple **AI-powered Streamlit web application** where users can ask questions about Afshan's journey in learning technology.
The app uses **Google Gemini AI** to generate responses about learning programming, building projects, and future goals in the tech industry.
## ⚙️ Technologies Used
* Python
* Streamlit
* Google Gemini API
## ✨ Features
* Ask questions about Afshan's tech journey
* AI-generated responses
* Simple interactive web interface
